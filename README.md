# anselmelly.com

Personal portfolio website for Ansel Melly - Statistician & Software Engineer.

## Live Site

[https://anselmelly.com](https://anselmelly.com)

## Tech Stack

- HTML5 / CSS3 / Vanilla JavaScript
- Google Fonts (Syne, DM Sans, DM Mono)
- Devicon for tech stack icons
- Interactive particle network animation

## Features

- Responsive design with dark/light mode support
- Interactive hero section with particle network
- Consultancy showcase
- Portfolio/client gallery
- Tech stack display with icons
- Testimonials section
- Contact form
- SEO optimized with meta tags, sitemap, and robots.txt
- AI-friendly with llms.txt for discoverability

## Structure

```
.
├── index.html          # Main HTML file (homepage)
├── post.html           # Legacy ?slug= post URL, redirects to /stories/<slug>/
├── post-template.html  # Template used to generate static story pages
├── build-posts.js      # Build script: stories/*.md + index.json -> stories/<slug>/index.html
├── styles.css          # Stylesheet
├── header.js           # Shared header/nav/theme-toggle behavior
├── sitemap.xml         # XML sitemap (post URLs regenerated by build-posts.js)
├── sitemap.xsl         # Sitemap stylesheet
├── robots.txt          # Crawler directives
├── llms.txt            # AI discoverability file
├── wrangler.jsonc      # Cloudflare Workers static assets config
├── stories/
│   ├── index.html      # Stories listing page
│   ├── index.json      # Post metadata (title, date, excerpt, tags, etc.)
│   ├── <slug>.md        # Post source content
│   └── <slug>/index.html  # Generated static post page (build output)
└── assets/
    ├── logo.png
    ├── profile_picture.jpg
    ├── AnselMelly_Resume.pdf
    ├── showcase/       # Portfolio images
    └── clients/        # Client logos
```

## Local Development

Install dependencies once:

```bash
npm install
```

Build the static story pages (run after adding/editing anything in `stories/`):

```bash
npm run build
```

Serve locally with Wrangler (replicates Cloudflare's static asset routing, including clean URLs like `/stories/`):

```bash
npm run dev
```

Or just serve the files with any static server (clean URLs won't resolve without `.html`/`/`, but everything else works):

```bash
python3 -m http.server 8000
```

## Deploy

```bash
npm run deploy
```

Runs the build then `wrangler deploy`.
